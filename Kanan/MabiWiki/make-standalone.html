Make the standalone wiki

This packs the wiki in this folder (index.html, app.css, the scripts and lib/) into one file, MabiWiki_Standalone.html: the page players keep in their Mabinogi folder, which sets itself up from their game files. Change the code here, then make the standalone page from it.

  1. Click Choose folder and pick this folder (MabiWiki_Hostable). Your browser may call it an upload: nothing leaves your computer.
  2. MabiWiki_Standalone.html downloads. Put it in the Mabinogi folder (the one with the package folder in it).
